# Allan 與阿拉蕾的橋牌桌

四人合約橋牌互動網站。你扮演南家 **Allan 顧問**，與北家 AI 小助手 **阿拉蕾** 搭檔，對抗西家「駭客小黑」與東家「釣魚怪」。

## 功能

- 完整的合約橋牌流程：發牌、叫牌（含 X / XX）、首引、夢家攤牌、打牌、復式計分、16 副局況循環
- AI 叫牌：簡化標準美式（五張高花、1NT 15–17、強 2♣、弱二、Stayman、爭叫、技術性賭倍）
- AI 打牌：首引、跟牌、王吃、清王、樹立長門等基本技巧
- 角色對話：繁體中文，使用瀏覽器 Web Speech API 的台灣華語語音（Allan 男聲、阿拉蕾年輕女聲），表情圖會依情境切換
- 「阿拉蕾提示」：建議叫品或出牌並說明理由
- 叫牌紀錄可查看每個叫品的意義；每副結束可重打或檢視四家原始牌
- 規則說明頁 `rules.html`：叫牌、打牌、計分表、局況、術語與本遊戲制度

## 執行

純靜態網站，不需要建置：

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

也可以直接用 GitHub Pages 發佈（已附 `.nojekyll`）。

## 語音

語音品質取決於裝置上安裝的語音。Windows / Edge 建議安裝「Microsoft Yunjhe」（台灣男聲）與「Microsoft HsiaoChen」（台灣女聲）；沒有台灣男聲時，會以較低音調模擬 Allan 的聲音。可在「⚙ 設定」手動選擇聲音與語速。
